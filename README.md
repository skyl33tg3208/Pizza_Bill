Kenny's Pizza Calculator 🍕

A simple Python program I created to practice control flow, if/else statements, conditional operators, and nested if/elif statements. This program calculates the final bill for a pizza order based on user choices.

Learning Goal

This project was created as part of my journey to strengthen my Python fundamentals, especially in decision-making logic. It demonstrates my understanding of:

Conditional statements (if, elif, else)

Nested logic (e.g., adding pepperoni costs differently based on pizza size)

Taking user input and performing calculations dynamically

It’s a small but practical example that shows I can apply Python logic to real-world scenarios, which I’m using to grow my programming portfolio.

Features

Choose pizza size: Small (S), Medium (M), or Large (L)

Add pepperoni (extra cost based on size)

Add extra cheese

Calculates and prints the final bill

How it Works

Prompts the user for pizza size.

Prompts for additional toppings (pepperoni, extra cheese).

Uses if/elif/else statements to calculate the total bill.

Prints the final amount.

How to Run

Make sure you have Python 3 installed.

Clone the repository:

git clone https://github.com/skyl33tg3208/Pizza_Bill.git


Navigate into the folder:

cd Pizza_Bill


Run the program:

python Pizza_Bill.py
