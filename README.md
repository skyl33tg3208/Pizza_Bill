# Kenny's Pizza Calculator 🍕

A simple Python program that calculates the final bill for a pizza order based on user choices. This project is part of my 100-day Python coding challenge to build skills and create a portfolio.

## Learning Goal

Created to strengthen my Python fundamentals by practicing **if/else statements**, **nested logic**, and **conditional operators**. This project demonstrates how to apply decision-making logic to solve real-world problems.

## Features

- Choose pizza size: Small (S), Medium (M), or Large (L)  
- Add pepperoni (extra cost varies by pizza size)  
- Add extra cheese option  
- Calculates and displays the final bill

## How to Run

1. Make sure Python 3 is installed on your system.

2. Clone the repository:
   ```bash
   git clone https://github.com/skyl33tg3208/Pizza_Bill.git
   ```

3. Navigate to the project folder:
   ```bash
   cd Pizza_Bill
   ```

4. Run the program:
   ```bash
   python Pizza_Bill.py
   ```

## Example Usage

```
Welcome to Kenny's Pizza!
What size pizza do you want? S, M, or L: M
Do you want pepperoni on your pizza? Y or N: Y
Do you want extra cheese? Y or N: N
Your final bill is: $23.
```
